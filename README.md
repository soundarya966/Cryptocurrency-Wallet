# Cryptocurrency Wallet using Java

## Overview
This project is a beginner-friendly cryptocurrency wallet simulation developed using Java. The application allows users to create wallets, send and receive cryptocurrency, maintain balances, and track transaction history.

The project demonstrates fundamental blockchain-inspired concepts such as:
- Digital wallets
- Cryptocurrency transactions
- SHA-256 hashing
- Balance management
- Secure wallet address generation

---

# Features

- Create cryptocurrency wallets
- Generate unique wallet addresses
- Send cryptocurrency between users
- Receive cryptocurrency
- Maintain wallet balances
- Store transaction history
- Console-based application

# How It Works

1. Users create wallets
2. Each wallet receives a unique wallet address
3. Users can transfer cryptocurrency
4. Balances are updated automatically
5. Transactions are stored and displayed
